
# Dataset Information

Dataset Name: Support Ticket Dataset

Platform: Hugging Face

Publisher: s2pidape

Source:
https://huggingface.co/datasets/s2pidape/support-ticket-dataset

Configuration: humans_only

License: CC BY 4.0

Dataset Type: Synthetic support ticket data.

The original dataset was sampled to obtain
a manageable subset for this project.

Modifications:
1. Selected relevant columns.
2. Renamed issue_description to ticket_description.
3. Removed missing required values.
4. Removed empty descriptions.
5. Removed duplicate ticket IDs.
6. Exported the prepared dataset as tickets.csv.
